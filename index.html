FAQ

Preguntas frecuentes.

¿Cuánto tarda en hacerse una web?

Depende del tamaño y las funcionalidades. Una web sencilla puede estar lista en pocos días, mientras que proyectos más completos requieren más tiempo.

¿La web funciona en móvil?

Sí. Todas las webs se diseñan para adaptarse a móviles, tablets y ordenadores.

¿Puedo pedir cambios?

Sí. Durante el desarrollo se revisa el proyecto y se realizan los ajustes acordados.

¿Podéis mantener mi web después de publicarla?

Sí. Puedes contratar un servicio de mantenimiento para realizar cambios y actualizaciones.
